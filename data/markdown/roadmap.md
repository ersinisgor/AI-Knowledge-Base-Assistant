# Product Roadmap — TechNova Solutions

Last Updated: 2025-01-15 | Owner: Emma Clarke (Product)

---

## Q1 2025 (January – March)

### AI Assistant MVP ✅
- Document ingestion (PDF, Markdown)
- Vector search with pgvector
- GPT-4o-mini answers with source citations
- Confidence scoring (HIGH / MEDIUM / LOW)

### Real-time Notifications ✅
- WebSocket-based notifications
- Task assigned, comment added, status changed
- Notification preferences per user

### Session History ✅
- Chat sessions persisted to database
- Users can resume past conversations
- Session list in sidebar with auto-generated titles

---

## Q2 2025 (April – June)

### Advanced Analytics Dashboard
- AI usage metrics (questions asked, documents ingested, top sources)
- Team-level query analytics
- Latency histograms and error rate charts

### Multi-language Support
- UI localization: English, Turkish, German, French
- AI assistant answers in the user's preferred language

### Slack Integration (Live)
- Connect to Slack workspace via OAuth
- Auto-ingest messages from selected channels
- Real-time updates when new messages are posted

---

## Q3 2025 (July – September)

### AI-powered Recommendations
- Suggest related documents when a user asks a question
- "You might also find this useful" panel in chat UI
- Proactive alerts when relevant new documents are ingested

### GitHub Live Sync
- Connect to GitHub repositories via GitHub App
- Auto-ingest commit messages, PR descriptions, and code comments
- Query codebase history naturally: "What changed in the auth module last week?"

### RAG Evaluation Harness
- Custom scoring pipeline to measure retrieval quality
- A/B test different chunking strategies and embedding models
- Dashboard showing precision, recall, and answer faithfulness metrics

---

## Backlog (No Fixed Date)

- DOCX and spreadsheet ingestion
- Role-based access control for document visibility
- On-premise deployment option
- Browser extension for quick knowledge lookups
